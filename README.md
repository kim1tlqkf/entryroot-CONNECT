# 엔트리 실시간 합작

엔트리 **작품 만들기** 화면(`playentry.org/ws/...`)에서 친구와 같은 작품을 동시에 고치는 크롬 확장입니다.
작품 데이터는 브라우저끼리 직접(P2P) 주고받고, 처음에 서로를 찾을 때만 PeerJS 공개 서버(`0.peerjs.com`)를 씁니다.
엔트리·네이버 커넥트재단과 관계없는 개인 제작물입니다.

## 설치

0. GitHub에서 받을 때: 저장소 페이지의 초록 **Code** 버튼 → **Download ZIP** → 압축 풀기
1. 크롬 주소창에 `chrome://extensions` → 오른쪽 위 **개발자 모드** 켜기
2. **압축해제된 확장 프로그램을 로드합니다** → 이 폴더(`manifest.json`이 있는 폴더) 선택
3. 엔트리 작품 만들기 화면을 새로고침하면 화면 아래 가운데에 **합작** 버튼이 생깁니다

함께 할 사람 모두 같은 버전을 설치해야 합니다(버전이 다르면 참여할 때 알려 줍니다). 새 버전을 받으면 `chrome://extensions`에서 새로고침하고 엔트리 탭도 새로고침하세요.

## 쓰는 법

**방장**
1. 함께 만들 작품을 엔트리에서 엽니다(새 작품이어도 됨)
2. **합작** → 내 이름 입력 → **새 방 만들기**
3. 나온 **초대 코드**(예: `abcd-ef23`)나 **링크 복사**로 친구에게 알려 줍니다
4. 작품 저장은 방장이 엔트리의 **저장하기**로 합니다. 방장이 창을 닫으면 방이 끝납니다

**참가자**
1. 엔트리 **새 작품 화면**(`playentry.org/ws/new`)을 엽니다 — 받은 링크를 열면 바로 이 화면으로 갑니다
2. **합작** → 내 이름 → 초대 코드 → **참여하기**
3. 내 화면의 작품이 방 작품으로 바뀌고, 그때부터 서로 고친 내용이 실시간으로 보입니다

다른 저장된 작품을 연 채로 참여하려고 하면, 그 작품을 덮어쓰지 않도록 새 작품 화면으로 옮겨서 참여합니다.

## 이렇게 동작합니다

- **같은 오브젝트에서도 서로 다른 블록 묶음**을 고치면 둘 다 남습니다.
- **같은 블록 묶음**(또는 같은 오브젝트의 같은 속성)을 거의 동시에 고치면, 먼저 보낸 사람 것이 남고 늦은 사람에게 알림이 뜹니다. 묶음을 나누거나 붙이는 사이 다른 사람이 그 묶음을 고친 경우도 같습니다(그 오브젝트는 먼저 보낸 쪽으로 맞춤). 다른 사람과 같은 오브젝트를 보고 있으면 화면 위에 미리 알려 줍니다.
- 누가 고치던 오브젝트를 다른 사람이 지우면 **지우기가 취소**되고(속성·코드·지역 변수·자리 그대로) 지운 사람에게 알립니다. 반대로 이미 지워진 오브젝트를 나중에 고치면 지운 것이 남고 고친 사람에게 알립니다.
- 블록 화면을 스크롤해도 다른 사람 화면은 움직이지 않습니다(각자 보는 위치가 따로).
- 내가 **실행 중**이거나 블록을 끄는 중, 함수를 편집하는 중이면 받은 변경을 잠깐 미뤘다가 끝나면 반영합니다. 보고 있는 오브젝트의 블록은 글자를 입력하는 중이나 블록 값 고르기 목록·오른쪽 클릭 메뉴가 열려 있는 동안에도 미룹니다. 모양을 그리는 중(저장 전)이나 엔트리 창(모양 추가 등)이 열려 있을 때는 작품을 다시 불러와야 하는 변경을 미룹니다. 합작 창에 "반영 대기"로 보입니다.
- 받은 변경을 화면에 넣다가 엔트리가 멈추면, 내 화면을 바로 전 상태로 되돌리고 방과 맞추기를 멈춘 뒤 **방 작품 다시 받기**와 **방 나가기** 중에 고르게 합니다(반쯤 빈 화면이 방으로 퍼지지 않게).
- 오브젝트가 **모두**, 또는 한 번에 **3개 이상·절반 넘게** 사라지면 방에 보내기 전에 멈추고 묻습니다(**방 작품으로 되돌리기** / **방에도 지우기**).
- 블록·오브젝트 속성·모양·소리·함수·변수·리스트·신호가 바뀌면 그 부분만 바꿔 넣습니다(큰 작품에서도 받는 쪽은 거의 멈추지 않음).
- **오브젝트 추가·삭제, 장면 추가·삭제**는 아직 작품을 통째로 다시 불러옵니다(보던 장면·오브젝트·탭은 그대로). 큰 작품에서는 이때 받는 쪽이 엔트리로 작품을 여는 시간만큼 멈춥니다.
- 처음 참여할 때도 엔트리가 작품을 여는 시간만큼 멈춥니다(작품을 그냥 열 때와 같은 시간). 그동안 "방 작품을 화면에 넣는 중"이 보입니다. 크롬이 "응답 없음"을 띄우면 **기다리기**를 누르세요.
- 큰 작품에서 블록 하나를 고칠 때 고치는 사람 화면이 1~2초 멈추는 건 엔트리·playentry 자체 비용입니다(합작을 꺼도 같음, 측정함).
- 인터넷이 잠깐 끊기면 2분 동안 다시 연결을 시도하고, 끊긴 동안 고친 것도 다시 붙으면 보냅니다.
- 다른 사람의 블록 변경이 내가 고치던 오브젝트에 들어오면, 그 오브젝트의 **되돌리기(Ctrl+Z) 기록은 비워집니다.** 엔트리의 되돌리기는 "몇 번째 묶음"처럼 위치로 기억해서, 남이 바꾼 뒤에 쓰면 남의 블록을 지울 수 있기 때문입니다.
- 참여 중에 다른 작품을 불러오면 방으로 보내지 않고 멈춘 뒤, **방 작품으로 되돌리기**와 **방 나가기** 중에 고르게 합니다.

## 확인한 것과 아직 확인하지 않은 것

자동 시험으로 확인한 것(`npm test`, `npm run e2e`):
- 실제 `playentry.org` 편집기를 크롬 2개로 열고, 확장을 설치한 채 실제 P2P로 연결해 다음을 확인: 방 열기·참여, 블록 추가가 양쪽에 보임, 같은 오브젝트에 동시에 다른 묶음 추가, 스크롤만 하면 아무것도 보내지 않음, 오브젝트 위치·이름 변경, 오브젝트·변수 추가, 실행 중 미루기, 실제 마우스로 블록 끌어다 놓기, 되돌리기가 남의 블록을 지우지 않음, 다른 작품 불러오기 보호, 같은 작품을 비웠다 다시 불러올 때 그대로 이어 감, 참가자 화면에서 불러오기가 실패해도 방 작품이 지워지지 않음, 값 고르기 목록·오른쪽 클릭 메뉴가 열린 동안 미루기, 방장 쪽이 20초 멈췄다 돌아왔을 때 다시 연결·끊긴 동안 편집 전달, 큰 묶음 나눠 보내기, 방 닫기
- 엔트리 없이 4명이 무작위로 편집(묶음 나누기·붙이기, 오브젝트 추가·삭제 포함)·지연·끊김을 겪는 흉내 시험에서 모두 같은 작품으로 모이고 블록이 두 군데 생기지 않음
- 별도 검토에서 나온 결함(불러오기 실패 시 방 작품 삭제 전파, 블록 중복, 지우기·고치기 반쪽 반영, 다시 연결 때 지운 것 되살림)을 재현 시험으로 만들어 고치기 전 실패 → 고친 뒤 통과를 확인
- 큰 작품(오브젝트 30개·블록 6,300개·약 2.7MB, `node tests/e2e/perf.js`)에서 화면 멈춤: 가만히 있을 때 10초 중 2.9초 → 0초, 블록 추가 때 받는 쪽 1.4초 → 0.15초, 변수 추가(다시 불러오기) 때 1.8초 → 0.4초. 블록 하나 추가에 엔트리 자체가 쓰는 0.22초는 합작을 꺼도 그대로입니다
- 실제 큰 작품(15.5MB, 오브젝트 28개, 함수 188개, `node tests/e2e/join-fixture.js <작품.json>`): 참여 11초(받기 0.9초 — 압축), 함수 고치기·변수·신호·모양 추가·큰 오브젝트 블록 추가 때 받는 쪽 멈춤 0.1초 이하, 다시 불러오기 없음, 편집 뒤 두 사람 작품 같음

아직 확인하지 않은 것:
- **서로 다른 컴퓨터·다른 인터넷**끼리의 연결(시험은 한 컴퓨터 안에서만 함). 학교·회사처럼 막힌 인터넷이나 일부 휴대폰 핫스팟에서는 직접 연결이 안 될 수 있습니다. 그런 곳에는 중계(TURN) 서버가 필요한데, 다른 확장이 쓰던 무료 공개 중계(`openrelay.metered.ca`)는 2026-10-25 시험에서 주소 조회부터 실패했고, Metered의 현재 무료 중계는 각자 가입해 받은 계정이 필요합니다. 그래서 중계는 넣지 않았습니다
- 로그인한 계정으로 **저장하기**를 누른 뒤(특히 새 작품을 처음 저장해 주소가 바뀔 때)의 동작
- 모양 그리기·소리 편집·함수 편집·글상자 편집이 섞인 실제 사용, 아주 큰 작품에서의 속도
- 하드웨어·인공지능·확장 블록을 쓰는 작품

## 알아 둘 점

- 초대 코드를 아는 사람은 누구나 방에 들어와 작품을 고칠 수 있습니다. 믿는 사람에게만 알려 주세요.
- 방 작품은 방장 컴퓨터의 엔트리 화면에 있습니다. 중간중간 방장이 저장해 두세요.

## 만든 사람용

```
src/merge.js          작품 ↔ 조각 나누기, 3방향 합치기, 정리
src/sync.js           방장(순서 매기기·합치기)과 참가자(내 편집기와 맞추기)
src/entry-adapter.js  엔트리 편집기 읽기·부분 반영·다시 불러오기·안전 판단
src/net.js            PeerJS 연결, 큰 메시지 나누기, 연결 끊김 감지
src/ui.js, main.js    화면과 연결
tests/unit            node 시험(엔트리 없이)
tests/e2e             실제 엔트리를 크롬 2개로 여는 시험(크롬 설치 필요, 저장하지 않음)
                      run.js 기능 시험, perf.js 큰 작품 멈춤 측정, profile.js 어느 함수가 시간을 쓰는지,
                      join-fixture.js 실제 작품 파일로 참여·편집 측정, host-edit-cost.js 편집하는 쪽 비용(합작 켬/끔 비교)
```

PeerJS 1.5.5(MIT, `vendor/peerjs.LICENSE`)를 포함합니다.
