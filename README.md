# 엔트리 실시간 합작

<img src="icons/128.png" width="64" alt="">

엔트리 **작품 만들기** 화면(`playentry.org/ws/...`)에서 친구와 **같은 작품을 동시에** 고치는 크롬 확장입니다.
따로 서버를 두지 않고 브라우저끼리 직접(P2P) 작품을 주고받습니다.

> 엔트리·네이버 커넥트재단과 관계없는 비공식 개인 제작물입니다.

## 할 수 있는 것

- 초대 코드(또는 링크) 하나로 방을 열고 들어오기 — 최대 8명
- 블록·오브젝트(위치·이름·모양·소리)·함수·변수·리스트·신호를 고치면 다른 사람 화면에 바로 반영
- 같은 오브젝트 안에서도 **서로 다른 블록 묶음**은 동시에 고칠 수 있음
- 누가 어느 오브젝트를 보고 있는지 표시, 같은 오브젝트를 보고 있으면 미리 알림
- 인터넷이 잠깐 끊겨도 다시 붙으면 그동안 고친 것까지 맞춰 줌

## 설치

1. 이 저장소 페이지의 초록 **Code** 버튼 → **Download ZIP** → 압축 풀기
2. 크롬 주소창에 `chrome://extensions` → 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** → 압축 푼 폴더 중 `manifest.json`이 있는 폴더 선택
4. 엔트리 작품 만들기 화면을 새로고침하면 화면 아래 가운데에 **합작** 버튼이 생깁니다

함께 하는 사람 모두 **같은 판**이어야 합니다(합작 창 맨 아래에 `v0.2.4`처럼 보임). 새 판을 받으면 `chrome://extensions`에서 새로고침하고 엔트리 탭도 새로고침하세요.

## 쓰는 법

**방장**
1. 함께 만들 작품을 엔트리에서 엽니다(새 작품이어도 됨)
2. **합작** → 내 이름 → **새 방 만들기**
3. **초대 코드**(예: `abcd-ef23`)나 **링크 복사**로 친구에게 알려 줍니다
4. 작품 저장은 방장이 엔트리의 **저장하기**로 합니다. 방장이 창을 닫으면 방이 끝납니다

**참가자**
1. 받은 링크를 열거나, 엔트리 **새 작품 화면**(`playentry.org/ws/new`)을 엽니다
2. **합작** → 내 이름 → 초대 코드 → **참여하기**
3. 내 화면의 작품이 방 작품으로 바뀌고, 그때부터 서로 고친 내용이 실시간으로 보입니다

저장된 다른 작품을 연 채로 참여하려 하면, 그 작품을 덮어쓰지 않도록 새 작품 화면으로 옮겨서 참여합니다.

참가자도 엔트리 **저장하기**로 방 작품을 **내 계정에 내 작품으로** 저장할 수 있습니다(로그인 필요). 엔트리는 처음 저장할 때 그 작품 주소로 페이지를 새로 여는데, 새로 열린 페이지가 방금 저장한 그 작품이면 합작이 **같은 방에 자동으로 다시 들어갑니다**. 그다음부터 저장하기는 내 작품에 덮어씁니다. 실수로 새로고침해도(1분 30초 안) 같은 방으로 돌아옵니다. 스스로 **방 나가기**를 누른 뒤에는 다시 들어가지 않습니다.

## 알아 둘 점

- **같은 블록 묶음**을 거의 동시에 고치면 먼저 보낸 사람 것이 남고, 늦은 사람에게 알림이 뜹니다.
- 누가 고치던 오브젝트를 다른 사람이 지우면, 고친 것이 먼저 방장에게 닿았으면 지우기가 취소되고 지운 사람에게 알리고, 지우기가 먼저 닿았으면 고친 사람에게 반영되지 않았다고 알립니다.
- 실행 중이거나, 블록을 끄는 중, 글자를 입력하는 중, 블록 값 목록·오른쪽 클릭 메뉴가 열린 동안, 그림판에 저장하지 않은 그림이 있는 동안(그 오브젝트의 모양 변경만)에는 받은 변경을 잠깐 미뤘다가 끝나면 넣습니다(합작 창에 "반영 대기").
- **엔트리파이선** 화면을 보는 동안에는 남의 변경(그 오브젝트 블록, 함수, 작품 통째로 다시 불러오기가 필요한 것)을 블록 화면으로 돌아온 뒤에 넣습니다. 엔트리는 블록으로 돌아올 때 그 오브젝트의 블록과 함수를 글 내용으로 새로 만들어서, 그 전에 넣으면 지워지기 때문입니다.
- 한 오브젝트의 블록이 한꺼번에 모두 사라지면(엔트리파이선 글을 블록으로 못 바꿀 때 엔트리가 블록을 비움) 방에 보내기 전에 멈추고 묻습니다. 일부러 지운 게 아니면 **방 작품으로 되돌리기**를 누르세요.
- **엔트리루트**를 켠 사람과 안 켠 사람이 같이 고칠 수 있습니다. 엔트리루트 전용 블록은 방에 순정 블록으로 보냅니다. 플러그인 블록을 처음 쓰면 작품에 시스템 오브젝트·함수·리스트가 들어가 작품이 크게 늘고(시험 작품 2KB → 6.6MB), 다른 사람은 작품을 한 번 통째로 다시 불러옵니다. 블록에서 고른 "시간 속도" 같은 기본이 아닌 값은 고른 사람 화면에만 남고 다른 사람에게는 기본 블록으로 보입니다.
- 다른 사람의 변경이 지금 보고 있는 오브젝트, 또는 내가 고친 적 있는 오브젝트·함수에 들어오면 **되돌리기(Ctrl+Z) 기록이 모두 비워집니다.** 엔트리의 되돌리기는 위치로 기억해서, 그대로 두면 남의 블록을 지울 수 있기 때문입니다.
- **오브젝트·장면 추가·삭제**는 아직 작품을 통째로 다시 불러옵니다(오브젝트 순서 바꾸기·장면 이름 바꾸기는 그 부분만 바꿉니다). 큰 작품에서는 받는 쪽이 엔트리로 작품을 여는 시간만큼 멈춥니다. 처음 참여할 때도 같습니다. 크롬이 "응답 없음"을 띄우면 **기다리기**를 누르세요.
- 중계 서버가 없어서 **학교·회사처럼 직접 연결을 막는 인터넷**에서는 연결이 안 될 수 있습니다. 처음 서로를 찾을 때만 PeerJS 공개 서버(`0.peerjs.com`)를 거칩니다.
- 초대 코드를 아는 사람은 누구나 방에 들어와 작품을 고칠 수 있습니다. 믿는 사람에게만 알려 주세요.
- 방 작품은 방장 컴퓨터의 엔트리 화면에 있습니다. 중간중간 방장이 저장해 두세요.

## 안 될 때

합작 창 맨 아래 **문제 기록 복사**를 누르면 판 번호·진행 단계·최근 오류가 복사됩니다(작품 내용은 들어가지 않음). 이슈에 붙여 넣어 알려 주세요.

## 원리(짧게)

1. 작품을 **조각**으로 나눕니다 — 오브젝트마다 속성·코드, 함수·변수·신호 하나하나.
2. 누가 고치면 **바뀐 조각만** 방장에게 보냅니다.
3. 방장은 도착한 순서대로 번호를 매겨 모두에게 나눠 줍니다. 같은 조각을 동시에 고쳤으면 "원래 것 / 먼저 온 것 / 나중 온 것"을 비교해서 블록 묶음 단위로 합칩니다.
4. 받은 조각은 작품 전체를 다시 불러오지 않고 **그 부분만** 바꿔 넣습니다. 내가 지금 고치고 있는 조각은 건드리지 않습니다.
5. 큰 데이터(처음 참여 때 작품 전체)는 압축해서 보냅니다.

시험·측정 기록은 [docs/검증-기록.md](docs/검증-기록.md)에 있습니다.

## 개발

```
src/merge.js          작품 ↔ 조각 나누기, 3방향 합치기, 정리
src/sync.js           방장(순서 매기기·합치기)과 참가자(내 편집기와 맞추기)
src/entry-adapter.js  엔트리 편집기 읽기·부분 반영·다시 불러오기·안전 판단
src/net.js            PeerJS 연결, 압축·나눠 보내기, 연결 끊김 감지
src/ui.js, main.js    화면과 연결
tests/unit            node 시험(엔트리 없이)
tests/e2e             실제 엔트리를 크롬 2개로 여는 시험(크롬 필요, 서버에 저장하지 않음)
tools/make-icons.js   아이콘 만들기
```

```
npm test        # 엔트리 없이 도는 시험
npm run e2e     # 실제 playentry.org에서 크롬 2개로 합작 흐름 시험
npm run fuzz    # 두 사람이 동시에 무작위로 고치고 작품·화면이 맞는지 확인(--seed로 재현, --replay로 같은 순서 다시)
npm run verify  # 공개 전 시험 전부 — 통과한 내용만 공개 사본 맞추기가 복사함
```

측정 도구: `tests/e2e/perf.js`(큰 작품 멈춤), `join-fixture.js <작품.json>`(실제 작품 파일로 참여·편집), `host-edit-cost.js <작품.json>`(편집하는 쪽 비용, 합작 켬/끔 비교), `profile.js`(어느 함수가 시간을 쓰는지).
